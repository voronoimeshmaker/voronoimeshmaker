O Que É O VMM?
==============

O VMM é uma biblioteca C++20 para preparação de malhas Voronoi de volumes
finitos. O produto central é uma malha canônica auditável, com nós, células,
faces, relações owner/neighbour, patches de fronteira e metadados de exportação.

O foco imediato está nas tabelas FV 2D, auditorias e diagnósticos.
