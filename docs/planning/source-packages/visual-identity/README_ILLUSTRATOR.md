# Illustrator-ready SVG assets

These SVG files are intended to be opened in Adobe Illustrator or Inkscape.

## Files

```text
vmm_logo_dark_editable.svg
vmm_logo_print_negative_editable.svg
vmm_icon_dark_editable.svg
vmm_icon_print_negative_editable.svg
vmm_palette_board_editable.svg
```

## Editing notes

- The cracked/Voronoi icon is composed of separate editable vector paths.
- The wordmark text remains editable text where possible.
- The letter seams are separate editable objects under `editable-letter-seams`.
- If the font is not available, Illustrator will substitute it. Suggested families: Orbitron, Rajdhani, Eurostile, Bank Gothic, Montserrat.
- For final production, convert the approved wordmark to outlines after selecting the final font.
- Keep the design minimal. Do not add gradients, shadows, 3D effects or excessive detail.
