## What Codex should do with this

Use this as the visual reference for future documentation, README assets, Sphinx theme styling, landing page mockups and GitHub presentation material.

Do not attempt to derive exact vector geometry from these PNG files yet. Treat them as approved concept art and brand direction. A future step should recreate the logo as SVG with controlled paths, typography and spacing.

## Important design notes

- The concept should remain minimalist.
- The cracked circular icon is deliberately closer to cracked earth than to a thin mathematical graph.
- The typography direction is modern, segmented and technical.
- The project name should be split across two lines in the main stacked mark:

```text
Voronoi
Mesh Maker
```

- The dark mark is for digital dark backgrounds.
- The negative mark is for white pages and printing.

## Illustrator-ready vector standards

The folder `illustrator_svg/` contains editable SVG files for Illustrator. These are not pixel-perfect traced versions of the generated PNGs; they are clean vector standards that preserve the approved visual direction and can be refined manually.

Use these as the starting point for final SVG, PDF or AI production assets.
