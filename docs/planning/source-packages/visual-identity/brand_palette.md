# Voronoi Mesh Maker, visual identity palette

## Approved visual direction

The approved direction is minimalist, technical and geometric, with a cracked-earth / Voronoi motif. The icon should look like a circular fractured terrain or Voronoi cell structure, using thick negative-space divisions.

The preferred lockup is stacked:

```text
[cracked Voronoi circular emblem]

Voronoi
Mesh Maker
```

The overall silhouette should feel like an inverted triangle, with the icon above, the shorter word line in the middle and the wider `Mesh Maker` line below.

| Name | Hex | Role |
|---|---:|---|
| Deep Slate | `#263640` | Primary dark background and dark ink for print-negative logo |
| Off White | `#F5F7F8` | Primary logo colour on dark backgrounds and print background |
| Steel Blue | `#4C6A7F` | Secondary UI/documentation accent |
| Cool Graphite | `#3A434B` | Secondary dark neutral, borders, cards, code panels |
| Teal Accent | `#3FA7A0` | Restrained accent for highlights, links and diagrams |

## Usage rules

1. Keep the logo minimalist.
2. Preserve the thick cracked-earth / Voronoi icon style.
3. Use the dark version on Deep Slate or similarly dark backgrounds.
4. Use the negative version for white pages, reports and printed material.
5. Avoid gradients, 3D effects, excessive shadows and decorative textures.
6. Use Teal Accent sparingly.
7. For small sizes, use the icon alone rather than the full text lockup.

## Typography direction

Use a modern futuristic segmented sans-serif direction. The lettering may be subtly Voronoi-inspired, with controlled cuts or seams, but must remain readable. Avoid overly fractured text in documentation headers or small sizes.
